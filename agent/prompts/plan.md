# Prompt — PLAN

```
Read first, do not skip:
- AGENTS.md
- agent/policy.md
- agent/rules/<relevant rule file>
- The "MINGGU <N>" section of the roadmap
- The current state of the files you intend to touch (read them, do not assume)

TASK: <describe the task>

Produce a plan only. No code yet. Include:
1. Restatement of the task in your own words, and what you understand the
   Definition of Done to be.
2. Exact list of files to create or modify, with one line on why each.
3. Order of work, and where you will stop to verify.
4. The commands you will run to prove it works, and which evidence files
   they will produce.
5. Risks: what could break, what is unclear, what you cannot verify locally.
6. Anything requiring a human (credentials, cloud actions, decisions).

If anything is ambiguous or touches a hard stop in agent/policy.md, use the
STOPPING format and ask instead of guessing.
```
