# Prompt — TEACH (understand existing code)

```
Explain <file / function / concept> to me.

I am a final-year IT student, comfortable with frontend, backend, and
Supabase, currently learning infrastructure and AI engineering. Assume I
know programming; do not assume I know this specific area.

Structure your explanation:
1. What problem this solves, in plain language, before any jargon.
2. Walk through the actual code in this repo, in execution order. Quote the
   real lines with file:line references — do not paraphrase code that exists.
3. The non-obvious parts: what would I get wrong if I wrote this myself?
4. What breaks if I remove it or get it wrong?
5. The alternatives we did not choose, and what they would cost.
6. One command I can run right now to see this behaviour with my own eyes.
7. The interview question a hiring manager would ask about this, and a
   strong answer.

If I already have a misunderstanding visible in my question, correct it
directly. Do not be polite about it at the expense of clarity.
```
